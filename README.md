# Overview
Zepto iOS is a SwiftUI-based e-commerce application that allows users to browse products, add them to a cart, and place orders. The app includes authentication, product listings, and order history while leveraging Core Data for local storage.
# Features
- User authentication with OTP verification
- Product listing with detailed views
- Shopping cart with quantity management
- Core Data integration for user details and previous orders
- Smooth and responsive UI using SwiftUI
- NavigationStack for structured app flow

# Tech Stack
- Language: Swift
- Framework: SwiftUI, Combine
- State Management: @State, @FocusState
- Database: Core Data
- Navigation: NavigationStack
- API Handling: Combine
